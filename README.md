# سرکٹ ٹرینر (PWA)

بجلی کے سرکٹ بنانے اور سمجھنے کی ایپ۔ انٹرنیٹ کے بغیر بھی چلتی ہے، موبائل اور کمپیوٹر دونوں پر۔

## فائلیں
- `index.html` — پوری ایپ
- `manifest.webmanifest` — ایپ کا نام، آئیکن، رنگ
- `sw.js` — آف لائن چلانے کے لیے
- `icons/` اور `screenshots/` — آئیکن اور تصاویر
- `.nojekyll` — گٹ ہب پیجز کے لیے (حذف نہ کریں)

## گٹ ہب پر ڈالنے کا طریقہ
1. github.com پر اکاؤنٹ بنائیں۔
2. نئی ریپوزٹری بنائیں۔ **نام یہ رکھیں: `آپکایوزرنیم.github.io`** (مثلاً `ali123.github.io`)، Public رکھیں۔
3. اس زپ کی **اندر والی فائلیں** (فولڈر نہیں) ریپوزٹری میں اپلوڈ کریں۔ `.nojekyll` بھی ساتھ جائے۔
   (اگر فائل مینیو میں چھپی فائل نظر نہ آئے تو کمپیوٹر پر "Show hidden files" آن کریں۔)
4. Settings ← Pages ← Source: **Deploy from a branch** ← Branch: `main` / `(root)` ← Save۔
5. ایک دو منٹ بعد `https://آپکایوزرنیم.github.io/` پر ایپ کھل جائے گی۔ پہلے اسے اپنے موبائل کے کروم میں کھول کر دیکھ لیں۔

## APK بنانے کا طریقہ (PWABuilder)
1. pwabuilder.com پر اپنا ویب ایڈریس ڈال کر Start دبائیں۔
2. Manifest اور Service Worker دونوں کے آگے ٹک آنا چاہیے۔
3. Package for stores ← Android ← Generate۔ Package ID مثلاً `io.github.آپکایوزرنیم.circuittrainer` رکھیں۔
4. Signing key: "New" چنیں، اور ڈاؤن لوڈ ہونے والی کی (key) فائل اور پاس ورڈ **محفوظ جگہ رکھ لیں** — اپڈیٹ کے لیے یہی چاہیے ہوگی۔
5. زپ میں `.apk` فائل (اور `assetlinks.json`) ملے گی۔

## ایڈریس بار ہٹانے کے لیے (اہم)
PWABuilder کی زپ میں `assetlinks.json` ہوتی ہے۔ اسے گٹ ہب میں `.well-known/assetlinks.json` کے راستے پر اپلوڈ کریں،
یعنی ریپوزٹری میں فولڈر `.well-known` بنا کر اس کے اندر فائل رکھیں۔
اس کے بعد `https://آپکایوزرنیم.github.io/.well-known/assetlinks.json` کھل رہی ہو تو ایپ بغیر ایڈریس بار کے پوری اسکرین کھلے گی۔
(ریپوزٹری کا نام `آپکایوزرنیم.github.io` ہونا اسی لیے ضروری ہے؛ عام نام والی ریپو میں یہ فائل صحیح جگہ پر نہیں پہنچ سکتی۔)

## ایپ اپڈیٹ کرنا
1. `index.html` بدل کر گٹ ہب پر دوبارہ اپلوڈ کریں۔
2. `sw.js` کی پہلی لائنوں میں `VERSION` کا نام بدل دیں (مثلاً `circuit-trainer-v2-6-7`)۔
3. APK دوبارہ بنانے کی ضرورت نہیں؛ ایپ ہر بار ویب سے تازہ ورژن لیتی ہے۔
